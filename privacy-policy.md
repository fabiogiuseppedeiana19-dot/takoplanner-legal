## 2. QUALI DATI GESTISCE L'APP

TAK-O Planner non dispone di un proprio server e non trasmette automaticamente a Fabio Giuseppe Deiana i dati inseriti dall'utente.

I dati vengono conservati sul dispositivo dell'utente.

A seconda delle funzioni utilizzate, l'app può memorizzare:

* titolo, note, data e orario degli appuntamenti;
* priorità, tipo di attività ed etichette associate agli appuntamenti;
* promemoria impostati dall'utente;
* riferimenti agli allegati collegati agli appuntamenti;
* memo vocali registrati dall'utente;
* memo scritti;
* nome, numero di telefono, indirizzo email e indirizzo di eventuali contatti che l'utente sceglie esplicitamente di collegare a un appuntamento;
* preferenze di personalizzazione dell'app, quali tema, caratteri, colori e impostazioni analoghe.

### Contatti

Quando l'utente decide di collegare un contatto a un appuntamento, Android può consentire la selezione del singolo contatto tramite il selettore di sistema.

L'app non utilizza questa funzione per accedere indiscriminatamente all'intera rubrica dell'utente.

Le informazioni del contatto selezionato possono essere memorizzate nell'app in associazione all'appuntamento, secondo le modalità previste dalla funzione utilizzata.

### Dati che l'app non raccoglie per proprie finalità

TAK-O Planner non utilizza propri sistemi di analytics e non raccoglie per proprie finalità:

* dati di localizzazione;
* identificativi pubblicitari;
* statistiche di utilizzo personali;
* dati di navigazione o profilazione dell'utente.

## 3. PERMESSI E FUNZIONI DEL DISPOSITIVO

TAK-O Planner può utilizzare le seguenti funzioni del dispositivo esclusivamente quando necessarie per fornire le relative funzionalità.

### Notifiche

Le notifiche vengono utilizzate per mostrare all'utente i promemoria associati agli appuntamenti.

### Sveglie precise

L'app può utilizzare le funzionalità di Android relative alle sveglie precise per consentire l'esecuzione dei promemoria all'orario impostato dall'utente, quando necessario e consentito dalle impostazioni e dalla versione di Android.

### Riavvio del dispositivo

L'app può ricevere la notifica del riavvio del dispositivo per poter riprogrammare i promemoria precedentemente impostati, in modo che possano continuare a funzionare dopo un riavvio.

### Contatti

L'accesso ai dati di un contatto avviene quando l'utente sceglie esplicitamente di collegare un contatto a un appuntamento, attraverso le funzionalità di selezione dei contatti disponibili su Android.

### Microfono

Il microfono viene utilizzato esclusivamente quando l'utente avvia volontariamente la registrazione di un memo vocale.

La registrazione viene effettuata solo durante l'utilizzo della relativa funzione.

### File e allegati

L'app può accedere ai file che l'utente sceglie esplicitamente di collegare agli appuntamenti oppure ai file utilizzati per le funzioni di esportazione e importazione del backup.

## 4. CONDIVISIONE DEI DATI

TAK-O Planner non vende, affitta né condivide autonomamente con terze parti i dati personali inseriti nell'app.

Alcune funzioni possono tuttavia consentire all'utente di trasferire volontariamente informazioni al di fuori dell'app.

### Condivisione di appuntamenti

Utilizzando funzioni quali **"Condividi appuntamento"** o **"Condividi la giornata"**, l'app può aprire il menu di condivisione del sistema Android.

L'utente decide autonomamente:

* se effettuare la condivisione;
* quali informazioni condividere;
* quale applicazione o servizio utilizzare per la condivisione.

Una volta trasferite le informazioni a un'altra applicazione o servizio, il relativo trattamento è disciplinato dalla privacy policy del servizio destinatario.

### Esportazione del backup

Quando l'utente utilizza la funzione di esportazione del backup, il file viene creato e salvato nella posizione scelta dall'utente.

L'utente può scegliere, ad esempio, una posizione locale sul dispositivo oppure un servizio cloud disponibile attraverso il sistema di selezione dei file.

In quest'ultimo caso il file viene trasferito al servizio scelto dall'utente e il relativo trattamento è disciplinato dalle condizioni e dalla privacy policy di tale servizio.

TAK-O Planner non riceve né conserva una copia del backup sui propri server.

### "Offrimi un caffè"

Il pulsante facoltativo **"Offrimi un caffè"**, se presente nell'app, apre il sito web o l'applicazione PayPal tramite il sistema del dispositivo.

Il pagamento viene effettuato al di fuori di TAK-O Planner.

TAK-O Planner non gestisce direttamente i dati della transazione e non richiede un pagamento per utilizzare l'app.

Il trattamento dei dati effettuato da PayPal è disciplinato dalla privacy policy e dalle condizioni di PayPal.

---

## 5. BACKUP AUTOMATICO DI ANDROID

Il backup automatico integrato di Android è **esplicitamente disattivato nella configurazione di TAK-O Planner**.

I dati dell'app non vengono pertanto inclusi nel backup cloud automatico collegato all'account Google/Android tramite questo meccanismo e non vengono inviati automaticamente altrove per effetto del backup automatico di Android.

I dati restano sul dispositivo dell'utente, salvo le copie create volontariamente dall'utente tramite la funzione di backup manuale descritta nella sezione successiva.

---

## 6. BACKUP MANUALE

TAK-O Planner offre una funzione di backup manuale, avviata volontariamente dall'utente.

Sono disponibili, a seconda della versione dell'app, i seguenti formati.

### Backup completo (.zip)

Il backup completo può includere:

* appuntamenti;
* promemoria;
* etichette;
* allegati;
* memo vocali;
* altri dati necessari al ripristino dell'app.

### Backup semplice (.json)

Il formato JSON, mantenuto per compatibilità con versioni precedenti dell'app, può includere:

* appuntamenti;
* promemoria;
* etichette;

e non include gli allegati o i memo vocali.

Il file di backup viene creato solo in seguito all'azione dell'utente e viene salvato nella posizione scelta dall'utente.

Se l'utente sceglie un servizio cloud come destinazione, il file viene trasferito al servizio selezionato dall'utente.

TAK-O Planner non conserva una copia del backup sui propri server.

L'utente è responsabile della conservazione e della protezione dei file di backup esportati.

---

## 7. CONSERVAZIONE ED ELIMINAZIONE DEI DATI

Poiché TAK-O Planner non utilizza un proprio server per archiviare i dati dell'utente, i dati dell'app vengono conservati sul dispositivo dell'utente.

L'utente può eliminare i dati attraverso le funzioni disponibili nell'app oppure tramite le impostazioni del sistema operativo, inclusa, quando applicabile, la cancellazione dei dati dell'app o la disinstallazione dell'applicazione.

Gli eventuali file esportati manualmente dall'utente, inclusi i backup, devono essere eliminati separatamente dall'utente dalla posizione in cui sono stati salvati.

Analogamente, eventuali copie trasferite volontariamente a servizi di terze parti, come servizi cloud o applicazioni di messaggistica, sono soggette alle modalità di conservazione ed eliminazione previste da tali servizi.

Non disponendo di un server proprio per l'archiviazione dei dati dell'utente, Fabio Giuseppe Deiana non riceve automaticamente i contenuti inseriti nell'app.

L'utente deve tuttavia considerare che la sicurezza dei dati presenti sul dispositivo dipende anche dalle misure di sicurezza adottate sul dispositivo stesso, quali blocco schermo, aggiornamenti del sistema operativo e altre impostazioni di sicurezza.

I file di backup esportati dall'utente devono essere conservati in luoghi sicuri.
